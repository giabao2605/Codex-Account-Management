# Liquid Glass Phase 6 visual baselines

Ma trận baseline dành riêng cho giao diện PC 1440 × 1000 của Phase 6.

- Accounts: dark/light với hiệu ứng full, reduced và off.
- Usage: dark/light với hiệu ứng full.
- Import dialog: dark/light với hiệu ứng full.
- Dữ liệu chụp đến từ fixture đã khử nhạy cảm trong `tests/visual_baseline_app.py`.

Các ảnh trong thư mục này không thay thế baseline lịch sử của Phase 1 hoặc
Phase 4.
