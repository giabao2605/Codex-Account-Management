# Liquid Glass Phase 4 PC baselines

Các ảnh trong thư mục này dùng fixture công khai `example.test`; không chứa tài
khoản, OTP, token, password, secret hoặc profile thật.

Ma trận nghiệm thu chỉ dành cho PC theo quyết định ngày 2026-07-24:

- Accounts: Light/Dark × Full/Reduced/Off.
- Usage: Dark × Full.
- Import dialog: Light × Full.

Ảnh được tạo ở viewport 1440 × 1000 bằng Chrome qua Playwright.
